# Feed alta risoluzione — laboratorio

Questa directory contiene payload sperimentali di MeteoCasarano Lab.

## WRF

Dati meteorologici di origine MeteoHub, trasformati dal motore MeteoCasarano in riassunti spaziali di rischio.

Attribuzione dataset WRF:

Agenzia ItaliaMeteo-WRF consortium (CIMA-LaMMA)

Licenza dei dati sorgente: CC BY 4.0.

Fonte:
https://meteohub.agenziaitaliameteo.it/

Il payload presente in questa area è incompleto e serve esclusivamente per prove tecniche.
